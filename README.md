# OSINT - NETWORK DISCOVERY - AI ASSISSTED ATTACK SURFACE REPORT

## 📌 Overview

This repository consolidates the documentation of the 2nd Module mini projects including, OSINT & Digital Footprint Assessment, Network Discovery & Asset Inventory and AI-Assisted Attack Surface Report, that I completed as part of my Cybersecurity and Ethical Hacking internship in SureProEd.

## 🎯 Mini Projects

### 1. OSINT & Digital Footprint Assessment

- Passive and Active Reconnaissance
- DNS, Email and Web Footprinting
- Search Engine Reconnaissance
- Google Dorks and WEBINT
- Public Information Gathering

### 2. Network Discovery & Asset Inventory

- Host Discovery and OS Fingerprinting
- IP and Subnet Identification
- TCP, UDP and Port Scanning
- Service and Version Detection
- FTP, SMB, Telnet and SMTP Enumeration
- Network Asset Mapping

### 3. AI-Assisted Attack Surface Report

- AI-Assisted Scan Interpretation
- Attack Surface Classification
- False Positive Identification
- Risk Assessment
- AI-Generated Security Recommendations

## 🛠️ Tools Used

- **OSINT:** Google, Bing, WHOIS, DNSDumpster, MXToolbox
- **Network Scanning:** Nmap, Netdiscover
- **Network Analysis:** Wireshark
- **AI Analysis:** ChatGPT
- **Documentation:** Microsoft Word, Excel
